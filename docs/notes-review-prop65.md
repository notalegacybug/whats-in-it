# Notes to review: Prop 65 cancer listings (reference 2026.11.9)

Drafted for the owner to skim (~10 min). Mark anything wrong, unclear or not neutral; edit it in `data/notes/notes.json`, bump `data/version.json` and rebuild.

| Ingredient | Note | Caveat |
| --- | --- | --- |
| ETHYLBENZENE | A solvent made from petroleum, used in paints, inks and making plastics. It is also found in petrol and cigarette smoke, and is used in some fragrances. |  |
| ETHYLHEXYL ACRYLATE | A building block for plastics and acrylic glues, such as pressure-sensitive adhesives. In cosmetics it can be a leftover from making acrylic polymers. |  |
| RESMETHRIN | A synthetic insecticide of the pyrethroid family, used in household and garden insect sprays. |  |
| VINYL ACETATE | A chemical used to make polymers such as polyvinyl acetate (PVA) for glues, paints and coatings. It can remain as a leftover in those polymers. |  |
| MIBK | A solvent, also called methyl isobutyl ketone (MIBK), used in paints, varnishes and cleaning products, and sometimes in nail products and fragrances. |  |
| Pyridine | A solvent and chemical building block. It also forms when foods such as coffee are roasted or cooked, and is used as a flavouring. |  |
| DIETHANOLAMINE | A chemical used to adjust acidity and to make foaming agents (such as cocamide DEA) in shampoos and soaps, and in industrial products. |  |
| 4-AMINO-2-NITROPHENOL | A dye used in some permanent and semi-permanent hair colours. |  |
| BENZOPHENONE | A chemical that absorbs ultraviolet light, used to protect products and packaging from sunlight, and as a fragrance ingredient. It also occurs in some fruits. |  |
| PYROCATECHOL | A chemical, also called catechol, used in some hair dyes and in making other chemicals. It occurs in coffee and some fruits and vegetables. |  |
| ATTAPULGITE | A clay mineral, also called attapulgite or palygorskite, used to absorb oils and thicken products, and in cat litter. | Prop 65 lists long airborne fibres of this mineral (over 5 micrometres), mainly breathed in at work, not clay mixed into a product. |
| MYRCENE | A scent compound found in hops, bay leaves, lemongrass and other plants, used in fragrances and flavourings. |  |
| SODIUM O-PHENYLPHENATE | The sodium salt of o-phenylphenol, used as a preservative and disinfectant, including on harvested fruit. |  |
| CAPTAN | A fungicide used on crops and in some paints and products to stop mould. |  |
| CARBON BLACK | A fine black powder of carbon, used as a pigment in mascara, eyeliner, inks, plastics and tyres. | Prop 65 lists fine airborne carbon black dust that can be breathed in, mainly in workplaces, not pigment bound in a product. |
| DIPROPYL PYRIDINEDICARBOXYLATE | An insect repellent, also called R-326, used in some fly and insect sprays, often together with other repellents. |  |
| Potassium N-methyldithiocarbamate | A soil fumigant, also called metam-potassium, used in farming to control pests, weeds and fungi before planting. |  |
| ALLYLANISOLE | A scent compound, also called estragole, found in tarragon, basil, fennel and anise, used in flavourings and fragrances. |  |
| ETHYL ACRYLATE | A building block for acrylic plastics, paints and adhesives. It has also been used as a flavouring and can remain as a leftover in acrylic polymers. |  |
| FD&C violet No. 1 | A violet dye (Benzyl Violet 4B) once used in food and cosmetics in the US. It is no longer permitted in US food. |  |
| PIGMENT RED 53 | A red pigment (D&C Red No. 8) used in some cosmetics such as lipsticks and nail polish. |  |
| CAFFEIC ACID | A plant compound found in coffee, fruits, vegetables and herbs, used in some products as an antioxidant. |  |
| PIGMENT ORANGE 5 | An orange pigment (D&C Orange No. 17) that has been used in cosmetics and inks. |  |
| FD&C red No. 1 | A red dye (Ponceau 3R) once used to colour food. It is no longer permitted in US food. |  |
| PIGMENT RED 53:1 | A red pigment (D&C Red No. 9) used in some cosmetics such as lipsticks and nail polish. |  |
| SPIRONOLACTONE | A prescription medicine that lowers fluid build-up and blocks some hormone effects, used for heart conditions, high blood pressure and acne. |  |
| HYDROLYZED CARRAGEENAN | Carrageenan, a seaweed extract, broken down into smaller pieces. It is used in some skin products to condition skin. | Prop 65 lists degraded carrageenan (poligeenan). Regular carrageenan used to thicken food is a different form and is not on the list. |
| BASIC VIOLET 3 | A purple dye, also called gentian violet or crystal violet, used as an antiseptic, in some hair dyes and as a laboratory stain. |  |
| PROPYLENE GLYCOL T-BUTYL ETHER | A solvent used in cleaning products, inks and coatings. |  |
| TESTOSTERONE | The main male sex hormone, made in the body and also made for hormone medicines. |  |
| NITROFURAZONE | An antibacterial medicine, also called nitrofural, once used on wounds and burns and in animal care. |  |
| Acetamide | A chemical used as a solvent and in making plastics and other chemicals. It also forms in some foods such as roasted coffee and milk. |  |
| Citrus red No. 2 | A red dye used in the US to colour the skins of some oranges. It is not used inside the fruit. |  |
| TRICHLOROETHANE | A solvent, also called 1,1,1-trichloroethane or methyl chloroform, once widely used for cleaning metal and in sprays and glues. |  |
| POTASSIUM BROMATE | A chemical used to strengthen bread dough in some flours. It is not allowed in bread in the EU, the UK and several other countries. |  |
| BASIC VIOLET 10 | A pink-red dye, also called Rhodamine B, used in inks, plastics and laboratory work, and in some cosmetic colours. |  |
| Cinnamyl anthranilate | A flavouring that tastes like fruit. It is prohibited in food in the US. |  |
| D-PULEGONE | A scent compound found in pennyroyal and some mint oils, used in fragrances and flavourings. |  |
| O-PHENYLPHENOL | A preservative and disinfectant, also called 2-phenylphenol, used in cosmetics, household cleaners and on harvested citrus fruit. |  |
| 4-CHLORO-2-AMINOPHENOL | A chemical used in making hair dyes and other dyes. |  |
| Methyl acrylate | A building block for acrylic plastics, coatings and adhesives. It can remain as a leftover in acrylic polymers. |  |
| Furfuryl alcohol | A chemical used to make resins and as a solvent. It also forms when foods such as coffee, bread and fruit juices are heated. |  |
| DIMETHYLTOLYLAMINE | A chemical that makes acrylic resins harden quickly, used in acrylic nails, dental materials and bone cement. |  |
